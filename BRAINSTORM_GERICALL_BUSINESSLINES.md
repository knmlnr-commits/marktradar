## Playbooks: trigger → semi-automatische reactie (15 min)

> Top-3 per BL. Voor elke playbook: welke trigger, wie ondertekent, kern-boodschap, of het direct mag of review-first via account-eigenaar.

### Format per playbook

```
BL:                _______________
Trigger:           _______________________________________________
Account-scope:     [ ] alleen bestaande klanten   [ ] alleen prospects   [ ] beide
Ondertekenaar:     [ ] directie   [ ] account-eigenaar   [ ] BL-lead
Kern-boodschap:    _______________________________________________
Vervolg-actie:     [ ] todo voor eigenaar   [ ] concept-mail   [ ] opp aanmaken   [ ] meeting-aanvraag
Review-first?      [ ] ja, eigenaar reviewt voor verzending   [ ] nee, automatisch
```

**Voorbeeld (referentie, vervangen):**
```
BL:                Eerste lijn
Trigger:           nieuw RvB-lid bij bestaande klant
Account-scope:     alleen bestaande klanten
Ondertekenaar:     directie
Kern-boodschap:    feliciteren + aanbod kennismaking + breedte-deck (alle 4 BL's)
Vervolg-actie:     todo voor eigenaar + concept-mail
Review-first?      ja, eigenaar reviewt voor verzending
```
